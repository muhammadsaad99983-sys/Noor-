اینڈرائیڈ پراجیکٹ (بند ایپ میں اذان کے الارم کے ساتھ)
1. کمپیوٹر پر Android Studio انسٹال کریں، پھر File > Open سے یہ فولڈر کھولیں (انٹرنیٹ چاہیے، Gradle خود ڈاؤن لوڈ ہو گا)۔
2. اپنی اذان کی فائل اس نام سے رکھیں: app/src/main/res/raw/adhan.mp3 (فائل نہ ہو تو فون کی ڈیفالٹ آواز بجے گی)۔
3. فون جوڑ کر Run دبائیں۔ پہلی بار لوکیشن، کیمرہ، نوٹیفکیشن اور Alarms & reminders کی اجازت دیں۔
4. پلے اسٹور کے لیے: Build > Generate Signed Bundle / APK > Android App Bundle۔
نوٹ: یہ پراجیکٹ میں یہاں کمپائل کر کے نہیں چلا سکا۔
